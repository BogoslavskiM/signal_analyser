# User Reporting

После review agent reports напиши человеку короткий отчёт в чате до нового
backlogging cycle.

В отчёт включай только:

- что завершено;
- что проверено;
- ключевые решения или findings;
- текущие blockers и следующий шаг.

Не включай внутренние agent IDs, сырые handoff, секреты или технические детали,
которые не помогают человеку понять состояние работы. Отчёт не означает
deployment или user acceptance, если это не подтверждено отдельно.
