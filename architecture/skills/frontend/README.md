# Скиллы Frontend

Порядок: `task-analysis`, затем `implementation` с подпунктами `zoning`,
`zone-structure-api`, `styling`. Для zoning используй корневые инструкции;
остальные подпункты имеют отдельные skills и bundled examples. Базовый формат
результата — HTML + JS + CSS; нестандартные зоны разрешены.

Дополнительные component subskills подключаются только по trigger:

- foundation: `frontend-project-structure`, `zone-composition`;
- controls/zones: `application-toolbar`, `settings-controls`, `inspector-ui`,
  `multi-page-element`, `graph-output-zone`, `output-loading-flow`;
- dialogs/export: `dialog-system`, `file-browser-dialog`,
  `session-import-export-ui`, `object-export-dialog`.
