# Скиллы backend-разработчика

Backend-скиллы охватывают Julia, Genie API, математические функции, поведение
приложения во время выполнения, сохранение, импорт и backend-контракты.

Добавляй сюда скилл только для повторяемой проектной процедуры. Базовые правила
передачи задач, отчетности, проверки и границ уже находятся в
`architecture/agents/roles/backend.toml`.

Доступные скиллы:

- `julia-genie-change/` — изменения Julia/Genie backend и поведения сигналов.
- `state-model/` — инспектор, стабильные идентификаторы объектов,
  типизированные draft-настройки, полный payload таблицы, мутации и состояние
  представления.
- `api-contract-planning/` — API-контракты таблицы инспектора, настроек,
  валидации, Apply и выходных данных.
- `apply-calculation-flow/` — ревизии Apply, состояния расчётов, очередь
  каждого инспектора, опрос состояния и защита от устаревших результатов.
- `calculation-planning/` — математические функции, кэши, выполнение очереди,
  зависимости общих вычислений и проверка ревизий.
- `export-to-workspace/` — передача уже подготовленного значения в workspace
  Engee с проверкой имени и разрешения перезаписи.
- `export-to-julia-script/` — воспроизводимый Julia script из подготовленного
  domain description без вычисления предметной математики.
- `export-to-jld2/` — запись подготовленных typed objects под явными JLD2 keys
  с атомарной заменой и round-trip.
- `export-to-engee-model/` — создание валидной `.engee` модели из
  подготовленного описания только через публичный `engee.*`.
