# Скиллы архитектора

Скиллы архитектора охватывают проектирование приложения, межролевые решения,
планирование передачи задач, интеграционную проверку и долговременную память
проекта.

Загружай только тот скилл, который нужен для текущей задачи.

Доступные скиллы:

- `app-creation-workflow/` — общий процесс создания типовых приложений группой
  агентов.
- `agent-handoff-plan/` — разделение работы на задачи реализации по ролям.
- `task-documentation/` — долговременное хранение задач, отчетов, бэклога и
  памяти проекта.
- `integration-review/` — межролевая интеграционная проверка и проверка
  результатов.
