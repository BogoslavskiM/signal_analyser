# Frontend documentation

Здесь хранится только стабильная документация текущего frontend: zones,
components, UI/API contracts, selectors и observable states. Task lifecycle и
межагентные результаты остаются соответственно в `tasks/` и `handoffs/`.

Документ добавляется, когда UI-контракт должен пережить конкретную task и нужен
следующим Frontend, Tester или E2E handoff.
