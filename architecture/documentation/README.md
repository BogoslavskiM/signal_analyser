# Документация

`architecture/documentation/` — память проекта: постановки задач, отчеты о
решениях, элементы бэклога и документация проекта.

## Файлы

- `tasks/` — один Markdown-файл на постановку задачи.
- `reports/` — один Markdown-файл на отчет о решении задачи.
- `backlog/` — один Markdown-файл на идею из бэклога.
- `project.md` — краткая документация проекта, полезная будущим агентам и людям.

По умолчанию архитектор поддерживает этот каталог на основе отчетов агентов и
переданных задач.
