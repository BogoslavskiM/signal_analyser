# Документация проекта

`example_project` — шаблон Julia/Genie-приложения со строгими зонами
ответственности агентов и переиспользуемыми скиллами.

Архитектурный workflow разделён на три части:

- `architecture/agents/` — контракты ролей и адаптеры инструментов;
- `architecture/documentation/` — задачи, отчёты, бэклог и сведения о проекте;
- `architecture/skills/` — переиспользуемые процедуры агентов.

Предметные решения конкретного приложения фиксируй в документации проекта, а не
в общих скиллах.
