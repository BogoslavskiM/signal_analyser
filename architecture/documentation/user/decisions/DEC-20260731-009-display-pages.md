# DEC-20260731-009: страницы Display с одним графиком

ID: `DEC-20260731-009`
Дата: 2026-07-31
Статус: accepted, implemented locally, runtime unverified
Supersedes: `DEC-20260731-003`

## Контекст

Первый каскад использовал постоянную сетку 2×2. Актуальное пользовательское ТЗ
разрешает добавлять несколько страниц Display, но откладывает редактор
multi-layout. На каждой активной странице сейчас нужен один самостоятельный
график выбранного типа.

## Альтернативы

Сохранить 2×2; реализовать MATLAB-подобный редактор раскладки; использовать
несколько Display pages с одним graph canvas на странице.

## Решение

Приложение поддерживает добавление, выбор и закрытие Display pages. Каждая
страница содержит один graph canvas и собственные `active_plot`, selection и
membership видимых сигналов. Checkbox списка изменяет membership только
активной страницы. Row selection остаётся отдельным состоянием. Редактор
multi-layout, docking и несколько ячеек внутри страницы не входят в текущий
контракт.

## Последствия

Переключение страниц восстанавливает их состояние. Закрытие последней страницы
запрещено, закрытие активной выбирает детерминированного соседа. Runtime E2E
должен проверять один ready host активной страницы и отсутствие влияния на
неактивные страницы.
