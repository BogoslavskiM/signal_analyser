# DEC-20260731-001: физическое разделение документации по аудитории

ID: `DEC-20260731-001`  
Дата: 2026-07-31  
Статус: accepted  
Supersedes: none

## Контекст

Один смешанный каталог одновременно обслуживал клиента и внутреннюю
координацию, создавая риск утечки служебных идентификаторов и противоречащих
копий.

## Альтернативы

Оставить общую плоскую структуру; разделить только тегами; физически разделить
по аудитории.

## Решение

`documentation/user/` — клиентский authoritative слой, `documentation/agents/`
— внутренняя память. Root README только маршрутизирует. Между слоями — ссылки,
не копии.

## Последствия

Навигация и skills используют новые paths. Клиентский слой исключает role IDs
и внутренние инструкции. Append-only history/ADR/reports/bugs сохраняют
решения; active tasks/backlog могут изменяться.
