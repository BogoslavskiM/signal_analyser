# Signals: встроенный браузер переменных

Дата: 2026-08-01

Статус: реализовано и развернуто; обычные тесты и статический интегральный E2E
пройдены; браузерный E2E runtime ожидает доступный CDP-сеанс

## Что готово

Команда `Signals → Добавить → Из рабочей области…` больше не требует ручного
ввода имени. Она открывает встроенный каталог переменных Engee с чекбоксами:

- можно выбрать сразу несколько переменных;
- raw-массивы используют одну явно заданную частоту дискретизации;
- timed-переменные получают частоту из собственных временных данных;
- несовместимые значения остаются видимыми с причиной, но их нельзя выбрать;
- один `Добавить` выполняет весь batch атомарно: либо добавляются все сигналы и
  столбцы матриц, либо состояние приложения не меняется;
- результат появляется в общем Signals и на активной Display; неактивные
  Display не меняются;
- обновление каталога сбрасывает выбор, а устаревший или изменившийся каталог
  не повторяет импорт без нового решения пользователя.

Каталог передает только имена и ограниченную метаинформацию. Значения,
отсчёты и preview в ответ каталога не входят. При добавлении backend разрешает
непрозрачные идентификаторы через ещё действующий snapshot каталога, повторно
проверяет метаданные и только затем читает выбранные значения.

## Аналитический review действий

| Действие | Назначение и иерархия | Состояния и обратная связь | Доступность и фокус | Итог |
| --- | --- | --- | --- | --- |
| `Добавить сигнал` | Основной icon-trigger локальной панели Signals; раскрывает два источника | `aria-expanded`, busy не закрывает меню оптимистично | `aria-haspopup=menu`; Enter открывает и передает фокус первому пункту | принято |
| `Из рабочей области…` | Основной путь импорта из Engee | loading, empty, error/Retry, loaded catalog | menuitem; после открытия фокус на заголовке, затем на первом доступном checkbox или Refresh | принято |
| `Из выбранного диапазона` | Создает новый сигнал из текущих Time Limits | disabled без применимого выбранного диапазона; server snapshot после успеха | отдельный menuitem, доступен Home/End/Tab lifecycle | принято |
| Checkbox переменной | Явный мультивыбор без ручного имени | несовместимые строки disabled и показывают причину; счетчик выбора live | native labelled checkbox, metadata/reason связаны с control | принято |
| `Обновить` / `Повторить` | Получает новый authoritative catalog | новый revision всегда сбрасывает checkbox-выбор; Retry показывается после ошибки | при пустом списке/ошибке является целевой точкой фокуса | принято |
| Частота дискретизации | Единый параметр только для выбранных raw-массивов | скрыта без raw; required/invalid с inline error; не нужна timed | label, hint и active error через `aria-describedby` | принято |
| `Добавить` в диалоге | Единственная primary mutation для выбранного batch | disabled при нулевом/невалидном выборе; busy; `422` сохраняет форму; catalog conflict сбрасывает выбор | участвует в focus trap; Enter сам по себе не отправляет форму | принято |
| `Отмена` / крестик | Закрывает форму без изменения приложения | недоступны только во время операции | возвращают фокус trigger Add; overlay/Escape не закрывают форму | принято |
| `Готово` после импорта | Отдельно подтверждает authoritative success и число добавленных сигналов | форма сначала закрывается, затем открывается success dialog | единственная явная dismiss-кнопка; фокус возвращается к Add | принято |
| `Копировать` | Создает независимую копию выбранной строки | disabled без selection; server-authoritative результат | точный `aria-label` и tooltip; 40×40 px target | принято |
| `Удалить` | Destructive action выбранной строки | disabled для последнего сигнала; подтверждение называет target; cancel не мутирует; success требует `Готово` | `alertdialog`, focus trap и явные Cancel/Delete/Done | принято |

Диалог адаптируется к узкому viewport: метаинформация складывается в одну
колонку, при этом четырехрядная геометрия самого приложения не меняется.

## Проверка и развертывание

- Product/ordinary checkpoint: `522c4fc5bcbaa21e5dc412fe282d8ca498db8706`.
- Полные backend tests завершаются успешно; frontend static/behavior — `2/2`.
- На `https://engee.com` запущен exact SHA `522c4fc`; приложение, state и
  metadata-only catalog отвечают `200`, каталог имеет `Cache-Control: no-store`.
- E2E checkpoint `78368e7` статически проверен независимым review: точный
  девятизапросный workflow от ревизии `0` до `6`, bounded stale retry,
  отсутствие replay при изменении workspace и нулевой выход POST в production.
- Полный browser runtime пока не заявляется: доступный пользовательский Chrome
  запущен без CDP, а его перезапуск требует отдельного разрешения.

## Известное ограничение среды

Некоторые служебные globals, созданные внешними инструментами в том же Engee
`Main`, могут отображаться как несовместимые и недоступные для выбора. Julia
представляет их так же, как обычные пользовательские присваивания, поэтому
безопасно скрыть их по имени или типу нельзя. Для полного отделения нужен
host-level признак происхождения либо отдельное пространство пользовательских
переменных. Значения этих строк каталог не раскрывает.
