# Задачи

Каждая задача хранится в отдельном Markdown-файле.

Используй стабильное имя файла на основе идентификатора задачи, например
`save-export-refactor.md`.

Рекомендуемые разделы:

- Цель
- Контекст
- Владелец
- Роли
- Объем работ
- Вне объема работ
- Критерии приемки
- Проверка
- Переданные задачи
- Риски
