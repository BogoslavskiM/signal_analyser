# Внутренние отчёты

Здесь хранятся отчёты координации и исследований. Клиентские датированные
отчёты находятся в [`../../user/reports/`](../../user/reports/README.md).

Используй стабильное имя файла на основе идентификатора связанной задачи и даты
или порядкового номера, например `save-export-refactor-001.md`.

Рекомендуемые разделы:

- Задача
- Агент
- Краткий итог
- Измененные файлы
- Проверка
- Принятые решения
- Переданные задачи
- Оставшиеся риски
