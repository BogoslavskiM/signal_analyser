# Бэклог

Внутренняя изменяемая очередь; завершённые результаты архивируются в reports и
client history.

Каждая идея из бэклога хранится в отдельном Markdown-файле.

Используй стабильное имя файла на основе идентификатора идеи, например
`adapter-renderer.md`.

Рекомендуемые разделы:

- Идея
- Обоснование
- Приоритет
- Владелец
- Затронутые области
- Критерии перевода в задачу
- Риски
