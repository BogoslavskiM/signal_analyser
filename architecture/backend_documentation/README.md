# Backend documentation

Здесь хранится только стабильная документация текущего backend: domain model,
authoritative state, API и calculation/export contracts. Task lifecycle и
межагентные результаты остаются соответственно в `tasks/` и `handoffs/`.

Документ добавляется, когда контракт должен пережить конкретную task и нужен
следующим Backender, Frontend, Tester или Engee User handoff.
