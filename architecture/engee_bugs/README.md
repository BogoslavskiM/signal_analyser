# Баги Engee

Engee User создаёт здесь `ENGEE-<date>-<id>-<title>.md`. Файл содержит
environment, package/version, минимальное воспроизведение, expected/actual,
точную ошибку, повторяемость, изоляцию, влияние, workaround и regression
scenario. Незавершённая изоляция означает статус `suspected`. PAT и другие
секреты запрещены.
